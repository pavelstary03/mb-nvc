File naming: NNN_TYPE_DIR_SETTER, e.g. 001_IN_F_SUB
NNN = number 001–999
TYPE: IN = IN-SYSTEM  ·  OUT = OUT-OF-SYSTEM
DIR: F = FORWARD (ZONE IV)  ·  B = BACKWARD (ZONE II)
SETTER: EVK = EVKA  ·  LEA = LEA  ·  PRO = PROKY  ·  SUB = ŠUBI  ·  NON = NON-SETTER
Type, direction and setter are read from the file name. Files with a different name are not uploaded.
